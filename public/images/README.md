# Scene pictures

Put one picture per scene in this folder, using the exact filenames below.

## Tips for choosing pictures
- **Landscape** (wider than tall). 4:3 or 16:9 works best.
- **Big and clear**, at least 1000 px wide. In Google Images use *Tools → Size → Large*.
- **No text or captions** on the picture. Text makes the puzzle too easy and gives away the scene name.
- **Colourful, with lots of detail** spread across the whole picture. Big plain areas like empty sky are hard to place.
- Add **"painting"**, **"illustration"** or **"Amar Chitra Katha"** to a search to get cartoon/painted styles that kids love.
- If a picture is `.png` or `.webp`, either rename it to match the filename below or change the filename in Admin → Puzzle Scenes.

## If a search doesn't give good results
Try these extra words:
- **Bal Hanuman cartoon**, **kids illustration**, **Ramayana for children**: cartoon styles
- **Raja Ravi Varma**: classic paintings (good for scenes 3, 4 and 20)
- **Ramanand Sagar Ramayan**: TV-serial stills, which kids may recognise
- **Pinterest** or **wallpaper**: large, high-quality images

## Other ways to add pictures
- Change a filename in Admin → Puzzle Scenes, or upload a picture there. Uploads are saved in that browser only, so for the event day the files in this folder are more reliable.
- Any scene without a picture gets a colourful emoji placeholder, so the game works either way.
- After adding pictures, commit and push to GitHub and Vercel will redeploy automatically.
